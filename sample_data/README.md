# 样例数据

三份脏样例 + 一份干净对照，全部走同一条代码路径（没有脏样例特判）。
另外两份是复核台账：供应商主数据与红字发票清单，由 M7 单独读取，不参与三单匹配。

| 文件 | 单据 | 编码 | 埋的坑 |
|---|---|---|---|
| `orders_dirty.csv` | 采购订单 | UTF-8 BOM、CRLF | BOM、千分位 `"1,234.50"`、全角数字 `１２３４．５０`、哨兵 `-`、万元单位、重复表头（2 段）、多一列、中间空行 |
| `receipts_gb18030.csv` | 入库单 | GB18030、CRLF | 编码与声明不符、重复表头、引号内含换行（仓库名）、末行无换行且只有 5 列（截断） |
| `invoices_dirty.csv` | 发票 | UTF-8、LF | 同一发票号两行金额不同、税率 `13%` 与 `0.13` 混写、千分位、科学计数法发票号 `4.500123E+9`、哨兵 `N/A` |
| `orders_clean.csv` | 采购订单 | UTF-8、CRLF | 干净对照，导入后 0 隔离 |
| `supplier_master.csv` | 供应商主数据 | UTF-8、CRLF | 同一编码两个名称（别名合并）、编码带空格与小写、停用供应商、少登记一个采购单 |
| `credit_notes.csv` | 红字发票清单 | UTF-8、LF | 括号负数 `(250.00)`、全角负号 `－76.00`、千分位、万元单位、原发票号不存在、超额冲抵、写成正数、占位符 `N/A` |

跑出来的期望结论写在 `tests/fixtures/expected.py`：48 条记录、41 采纳、7 行隔离、
16 个三单键 = 匹配 8 + 差异 3 + 缺单 5、调整单合计 241.28 元。
复核台账的期望结论写在 `tests/fixtures/audit_expected.py`：供应商 10 家、
发票含税 402213.25、已冲抵红字 -98913.34、净额 303299.91、待确认 -500.59。
